# KeyShortcut
This background script runs on your computer for a extra boost of prodoctivity
if you have ever wanted to open a software like kicad, or claude, or even the hack clug resources. you can do a simple 3 key shortcut to open it
I built this because I have a windows computer and it takes too long to open programs since i have to search it and do a bunch of things since windows is so bloated. 

here is the keybinds that open its respective website or prgrm. 

SECTION OPENING KEY - > HACK CLUB STUFF = 'ctrl+alt+h'

slackKey = 'ctrl+alt+s'
stardanceKey = 'ctrl+alt+8'
lapseKey = 'ctrl+alt+l'



SECTION OPENING KEY - > WINDOWS AND SOFWARE STUFF = 'ctrl+alt+shift+1'

powershellKey = 'ctrl+alt+`'
sysInfoKey = 'ctrl+alt+i'
vscodeKey = 'ctrl+alt+v'
gitBashKey = 'ctrl+alt+b'



SECTION OPENING KEY - > HARDWARE STUFF = 'ctrl+alt+w'

onshapeKey = 'ctrl+alt+o'
kicadKey = 'ctrl+alt+k'
claudeKey = 'ctrl+alt+c'


things to keep in mind:
- you can ONLY open ONE section at a time, this is bc if there are more sites added it lets us have more keybinds not needing to worry about dupplicates.
- if programs don't open that means that you need to update its location in the code.
